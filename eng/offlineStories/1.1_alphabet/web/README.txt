A–Z alphabet reader — drop-in guide
===================================

Two taps per letter: the big "Aa" plays the letter NAME; the word plays the WORD.
The hamburger (top-left) opens the A–Z grid. Arrows / swipe move letter to letter.

REPLACE THE PLACEHOLDERS
------------------------
Images:  images/a.jpg  images/b.jpg ... images/z.jpg   (keep these names, .jpg)
Audio :  audio/a-name.mp3  audio/a-word.mp3 ... z-name.mp3  z-word.mp3

Words (approved): apple ball cat dog egg fish grape house igloo jug king log
mat nose owl pen queen rat sun tree umbrella vase water xylophone yolk zebra

WEB VERSION (Cloudflare)
------------------------
Deploy this whole folder as-is (index.html at the root).

OFFLINE SINGLE FILE (tablet)
----------------------------
From the folder ABOVE this one:  python3 bundle_abc.py
-> writes ABC-A-Z.html with everything embedded. Copy that one file to the SD card;
open it with the file manager's "Open with" -> a browser.
